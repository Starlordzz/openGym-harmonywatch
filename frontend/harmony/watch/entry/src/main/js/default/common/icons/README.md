These icons were drawn for this third-party Huawei FIT adaptation of Duarte Santos's
openGym (https://github.com/DuarteSantos8/openGym). They use original geometric artwork,
not Apple SF Symbols files or a system icon font. Code and artwork are AGPL-3.0-or-later.

To edit/recreate the checked-in PNGs, run scripts/harmony/draw-icons.py in a Python
environment with Pillow. Building/installing the watch app does not require Pillow.
