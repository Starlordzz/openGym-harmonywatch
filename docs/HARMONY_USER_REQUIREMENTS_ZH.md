# openGym 华为手表版：用户开发要求

更新日期：2026-11-14。

目标产品为 HUAWEI WATCH FIT 5 Pro 上的 openGym 配套应用，沿用本项目 Apple Watch 版的训练逻辑和功能体验，与现有 Android openGym 及 NAS 自部署服务配合使用。当前使用方式为个人开发、签名侧载和自用测试。

## 1. 产品范围与优先级

| 编号 | 要求 | 当前范围 |
|---|---|---|
| S01 | 按本项目 Apple Watch 版的逻辑开发华为手表版，尽可能覆盖其全部训练功能。 | 核心目标；平台差异逐项适配。 |
| S02 | 复用项目已有手机端，增加必要的华为手表适配。 | 现有 Android 客户端与手表协同。 |
| S03 | 沿用现有 NAS 自部署 openGym 服务、登录账号、计划与历史记录。 | 现有服务继续使用；接口变更按实际需要评估。 |
| S04 | 项目使用用户自己的应用身份和包名。 | 手表包名为 `host.msknet.opengym.fit`。 |
| S05 | 个人自签名、自用、完全不上架。 | 当前交付为侧载测试；服务开通与商店发布分别处理。 |
| S06 | 调查 Apple Watch 与 FIT 的能力差异，列出可直接实现、需要适配、服务准入及待验证的功能。 | 功能对照和平台能力调查。 |
| S07 | 表盘训练组件、Smart Stack。 | 用户明确取消。 |
| S08 | 系统力量训练会话、活动热量、华为运动健康记录写入。 | 用户明确延后，保留后续接入方向。 |
| S09 | 像好球 Pro、训记一样，在应用记组时自动开始手表系统的力量训练。 | 可行性调查已提出；跟随系统运动功能延后。 |
| S10 | 离开应用后的独立准时振动提醒。 | 用户明确调低优先级。 |
| S11 | 熄屏后持续采集、运动会话恢复及后台运行机制。 | 需要针对 FIT、Lite SDK 和目标固件调查与验证。 |
| S12 | 手表应用内休息结束振动。 | 2026-11-14 用户取消“休息结束系统通知”；保留前台倒计时、到期提示与震动。 |
| S13 | Wear Engine 申请支持鸿蒙智能穿戴与轻量级智能穿戴两类。 | 服务申请选择两类；当前工程与设备适配聚焦 FIT Lite。 |
| S14 | 核实 Lite 应用在全智能穿戴设备上的安装与兼容方式。 | 设备适配调查；其他型号的运行效果待验证。 |

### 已明确的范围调整

- 最初的“Apple Watch 全功能”目标，后来明确移除表盘组件与 Smart Stack，并延后系统运动、热量、健康写入。
- 2026-11-14 用户取消手机转发的休息结束系统通知：移除开关、测试通知、NOTIFY 授权入口和后台定时发送；保留手表前台倒计时、振动及常亮。
- 重量微调曾采用步长切换；最新要求为整数、小数各自独立按键。
- 服务申请范围为两类穿戴；当前可运行版本与实拍对象为 FIT 5 Pro。
- 2026-11-02：表冠逐格震动被取消（平台只有通知式震感）；休息提醒从“无限重复”改为两轮后自停；材料截图统一改为简体中文界面。
- 2026-11-03：中文默认不显示英文括号；空闲页的取证入口和心率开关在首个状态到达前不再抛异常。

## 3. 训练功能基准

以下功能继承“对齐 Apple Watch 版训练逻辑”的总目标，具体界面适配 FIT。

| 编号 | 要求 | 验收场景 |
|---|---|---|
| F01 | 展示从手机获得的训练计划、题程和当前训练。 | 今日计划、其他计划、无计划状态均可正常显示。 |
| F02 | 完整走通训练开始流程。 | 选择计划、称重或跳过称重、开始倒计时、进入训练。 |
| F03 | 展示当前动作、动作动画和上次成绩。 | 名称、动画、成绩与手机中的对应动作一致。 |
| F04 | 记录重量、次数和计时组。 | 调整后的数值进入实际组记录和同步数据。 |
| F05 | 沿用原版热身、左右侧、超级组与组完成状态。 | 对应训练类型和状态切换可操作、可识别。 |
| F06 | 沿用原版 RPE/RIR 等训练记录逻辑。 | 编辑、保存和回传后的含义保持一致。 |
| F07 | 支持完成组、跳过组、切换动作及后续组。 | 操作后动作、组索引、休息和记录状态一致。 |
| F08 | 展示组间休息倒计时及下一组信息。 | 倒计时、延长休息、跳过休息与下一组操作正常。 |
| F09 | 支持结束、保存、丢弃训练和训练汇总。 | 结果与手机侧训练状态一致，时长、组数等统计可读。 |
| F10 | 支持离线训练记录与恢复。 | 断连期间保存本地记录，恢复连接后继续同步。 |
| F11 | 核实手机结束、删除或丢弃训练后的手表状态处理。 | 应用内训练状态跨端一致；系统健康记录删除能力另行调查。 |
| F12 | 提供训练期间的防误触锁定及明确解锁操作。 | 锁定状态可识别，解锁后继续操作。 |
| F13 | 心率、运动和健康数据按实际设备能力接入。 | 本地心率权限、采集与展示在目标设备上验证；系统运动相关功能按后续优先级推进。 |

## 4. 用户单独强调的界面与交互

| 编号 | 要求 | 验收标准 |
|---|---|---|
| U01 | 字体可以与 Apple Watch 不同，字号和视觉层级应协调、接近原版。 | 主数字、倒计时、按钮与正文清楚可读，避免整体偏小。 |
| U02 | 动作名称使用中文，并与手机 App 一致。 | 手机与手表的动作名称对应；预填测试计划也使用中文名称。 |
| U03 | 修复首次启动“尚未同步”说明被裁切、遮挡的问题。 | 无手机、无计划时完整展示同步提示及底部入口。 |
| U04 | 修复“已存在手表上，稍后同步”等状态文字与 UI 重合。 | 训练、休息、结束、汇总等状态均有足够显示空间。 |
| U05 | Apple Watch 有、华为缺少现成资源的图标自行绘制。 | 完成、称重返回及其他图标有相近的含义和清晰外观，适配手表实际资源能力。 |
| U06 | 应用开启使用期间持续亮屏。 | 前台使用时请求常亮，离开应用时释放；主动熄屏和设备策略按系统行为处理。 |
| U07 | 重量调节支持小数。 | 编辑、显示、保存和回传保持小数精度，整数调节保留原有小数部分。 |
| U08 | 整数与小数调节分别提供按键。 | `-1`、`+1`、`-0.1`、`+0.1` 独立操作，取消原来的步长切换交互。 |
| U09 | 表冠轻转一次只推进一项。 | 2026-11-02 明确复现：一次转动跳两格。现为步进后锁定 450 ms，锁定期间到达的角度直接丢弃、不累计；一次转动只跳一格。 |
| U10 | ~~表冠有效步进有振动反馈~~ → **表冠不震动**。 | 2026-11-02 用户改为不要表冠震动：平台只提供通知式短/长震（`@system.vibrator` 仅 `mode: short/long`），逐格触发观感不对，故完全移除。 |
| U11 | 休息结束提醒要明显但**不能一直震**。 | 2026-11-02 定为两轮各三下长震（0/2/4 秒，10 秒后再一轮，约 14 秒）后自动停止；触摸或转表冠立即停止。原实现每 10 秒重起一轮、永不停止。 |
| U12 | 手表应用内休息结束振动。 | 两轮长震与触摸/表冠取消按 U11 验收；手机转发系统通知已由用户取消。 |
| U13 | 表冠按压及下键保持正常系统行为。 | 2026-11-02 仍复现“一按表冠就卡住”，应用内未定位。手表不能联网，无法用 hdc/hilog；改为空闲页长按 2 秒打开 debug 页，显示最近 7 条 show/hide 时间戳，供真机复现后截图取证。2026-11-03：debug 入口与空闲页心率开关在首个状态到达前不再抛异常，取证入口自身不会成为卡住的来源。 |
| U14 | 退出时完整释放运行资源。 | 隐藏、销毁后停止多余时钟、表冠、传感器和提醒，处理迟到的异步回调。 |
| U15 | 锁定按钮和系统功能的作用清楚。 | 应用内防误触锁的入口、状态、解锁方式容易理解。 |
| U16 | 设置页输入框必须能看见内容。 | 2026-11-02 真机复现：包名与指纹输入框白字落在白底卡片上不可见；已改为应用统一的两字段布局（标签在上、深色输入框在下）。 |
| U17 | 中文界面下动作名默认不带英文括号。 | 2026-11-03：默认按语言决定，`zh`、`zh-TW` 默认不带英文括号，其他语言保持带括号；设置页的“英文名括号”仍可逐语言手动开关。截图与真机展示使用纯中文名称（`杠铃卧推` 而非 `杠铃卧推 (Barbell Bench Press)`）。 |
| U18 | 界面截图一律使用简体中文。 | 2026-11-02 用户指出材料应为中文界面；英文界面截图不得进申请材料。 |

用户早期列出的第 6 项交互问题已补齐，即“按表冠后界面卡住”，见 U13（仍未定位，需真机复现取证）。

## 7. Lite 平台、构建、签名与安装

### 平台适配要求

## 11. 关键验收场景

1. 无手机、无本地存档：完整展示首次同步提示。
2. 预填测试计划：无手机也能开始、称重、记组、调小数、休息、结束和查看汇总。
3. 真实手机同步：计划、中文动作、动画、上次成绩与记录双向一致。
4. 断连与重连：记录保留，重新连接后补传与去重。
5. 表冠旋转：轻转单步（450 ms 内不重复）、**不震动**、编辑状态按预期调整；按下后不卡顿。
6. 重量编辑：四个独立按键可用，小数在显示、保存和回传中保持一致。
7. 休息结束：前台两轮各三下长震后自停，触摸或转表冠立即停止；自然到期与手机提前就绪快照的交互均覆盖。手机转发系统通知已取消。
8. 前台常亮：训练时保持请求，隐藏和退出后释放。
9. 表冠按压与退出：顺利返回表盘，系统按键和界面继续响应。
10. 安装与交付：最终签名包可在目标 FIT 安装，清单、SDK、权限和 BIN 一致。
11. 申请资料：两份 Excel 正常显示，网页与本地资料对应当前实际进度。
12. 文件管理：当前包与材料容易定位，源码和恢复后的未提交成果持续保留。
