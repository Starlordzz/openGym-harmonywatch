# 华为手表兼容性

更新：2026-11-14。

项目目标为 Android 手机与华为手表协同训练，覆盖圆表、方表等形态。型号支持按运行时、屏幕形态及真机验证结果分别记录。

| 对象 | 当前状态 |
|---|---|
| Android 手机 | Capacitor + Wear Engine 原生桥接，已完成双向通信与计划同步验证 |
| HUAWEI WATCH FIT 5 Pro | 当前真机，HarmonyOS 7.0.0.017；已确认计划下发、重开恢复、表冠退出、常亮及双端动作一致 |
| 其他 Lite Wearable 方表 | 同类运行时适配目标；分辨率、能力、安装与训练稳定性待验证 |
| 圆形华为手表 | 适配目标；圆屏安全区域、触控及表冠交互、运行时与接口兼容待适配验证 |
| 采用其他应用运行时的华为手表 | 需要核对应用模型、Wear Engine 能力与签名安装流程，再决定复用层和平台适配器 |

当前手表界面以 408×480 设计尺寸实现。后续多型号适配需要把可用区域、列表高度、图像布局及触控边缘抽为屏幕配置；圆屏应留出边缘安全区域。当前固定布局的多型号效果尚待验证。

每次新增型号须记录：完整型号、系统版本、运行时/API、屏幕形态与尺寸、APK/HAP 对应提交、签名安装、握手、计划保存恢复、训练回传、休息控制、震动、常亮、心率与退出结果。测试包的自动回归结果与型号实机结果分别保存。

`training-v2` 新增接收震动、双向休息控制及 128×128 动画；该版实机回归待手机重新接入。偶发退表盘等开放问题见[缺陷进度](../HARMONY_OPEN_BUGS_ZH.md)。
